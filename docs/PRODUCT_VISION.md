# ATLAS 제품 비전

ATLAS는 **자율형 AI 주식 투자 리서치·매매 시스템**이다. 최종 목표는 사람이 매일 종목을 고르는 도구가 아니라, 근거를 남기며 리서치하고, 위험을 제한한 뒤 **페이퍼 트레이딩**으로만 자동 집행하는 운영 체계다.

실계좌 연동은 이 문서의 범위 밖이다. 페이퍼 환경에서 의사결정·모델·성과가 장기간 검증되기 전에는 실거래 경로를 추가하지 않는다.

## 목표 파이프라인

```text
읽기 전용 수집 → 포인트-인-타임 이벤트 시계
        → LLM 리서치 에이전트 (설명·영향 종목)
        → 정량 ML (위험조정 수익·불확실성)
        → 다중 모델 결합
        → 확정적 리스크 제약 하 포트폴리오 최적화
        → 이벤트 기반 백테스트
        → PaperBroker 자동 집행
        → 결정·근거·모델 버전·예측 오차·성과 기록
```

모든 단계에서 `as_of`/`available_time`이 없는 데이터는 전략 입력으로 쓰지 않는다. LLM·ML 출력은 조언이며, `RiskManager`를 통과하기 전에는 체결되지 않는다.

## 비전 대비 현재 상태

| 능력 | 상태 | 현재 위치 | 공백 |
| --- | --- | --- | --- |
| 시세 (과거·현재) | 부분 | `atlas.market_data` 시뮬 바/호가 | 벤더 읽기 전용 수집, 저장소, 포인트-인-타임 조인 |
| 뉴스 | 부분 | `atlas.news` 호출자 제공 헤드라인 키워드 | 수집, 본문, 엔티티 연결, 이벤트 시각 |
| 공시·재무제표 | 부분 | `atlas.fundamentals` 호출자 제공 스냅샷 | 10-K/10-Q/8-K, 계정과목, 개정 이력 |
| 거시 지표 | 없음 | — | 시계열 계약만 정의됨 (`atlas.contracts`) |
| LLM 리서치 에이전트 | 없음 | — | 모델 호출 금지 상태. 산출물 계약만 정의 |
| 정량 ML | 없음 | `forecasting`은 휴리스틱 블렌드 | 피처, 학습, 불확실성 교정 |
| 다중 모델 결합 | 없음 | — | `EnsemblePrediction` 계약만 정의 |
| 포트폴리오 최적화 | 없음 | 주문 단위 수량 한도만 존재 | 가중치, 회전율, 노출 한도 |
| 이벤트 기반 PIT 백테스트 | 부분 | `BacktestEngine`이 바를 순서대로 BUY | 룩어헤드, 다음 봉 체결, 멀티 심볼 시계 |
| 페이퍼 자동 집행 | 구현 | `PaperBroker` + `RiskManager` | 세션 영속화, 재시작 후 decision 레지스트리 |
| 감사·성과 기록 | 부분 | `PaperFill`, `decision_id` | 근거 그래프, 모델 버전, 예측 오차 저널 |
| 실거래 | 의도적 부재 | `safety`가 LIVE 거부 | 추가하지 않음 |

**이미 지켜야 할 구현:** 페이퍼 전용 모드, 거절된 `RiskDecision`의 영구 비실행, 체결 시점 장부 재검사, 불완전 마크 시 `equity is None`, 시뮬 체결가와 `reference_price` 분리, 자격 증명 비커밋.

## 데이터 계약 원칙

코드의 정본은 `atlas.contracts`이다.

1. **시간은 timezone-aware datetime**만 허용한다. naive datetime은 거부한다.
2. **`TimeIndex`**  
   - `event_time`: 세계에서 사실이 발생한 시각(또는 봉의 거래 시각).  
   - `available_time`: 전략이 그 사실을 **알 수 있게 된** 최초 시각.  
   - `ingested_time`: ATLAS가 로컬에 적재한 시각.  
   룩어헤드 금지: `available_time >= event_time`.
3. **`Provenance`**  
   - `simulated`: 소프트웨어 픽스처. 실시세로 표시하지 않는다.  
   - `caller_supplied`: 테스트·연산자가 넣은 값.  
   - `vendor_read_only`: 향후 읽기 전용 벤더. 아직 HTTP 클라이언트를 붙이지 않는다.
4. **시세**는 OHLC 관계를 만족하는 바/호가만 적재한다.
5. **공시·제표**는 회계기간 종료(`event_time`)와 공시 시각(`available_time`)을 분리한다.
6. **리서치 산출물·예측**은 `model_id`, `model_version`, 대상 심볼, 근거 ID를 가진다. 텍스트만으로 주문을 만들지 않는다.
7. **예측**은 점추정과 불확실성(유한, 음수 아님)을 함께 둔다.

## 안전

- 페이퍼 트레이딩만 허용한다.
- 외부 서비스 연결은 별도 승인 후에만, 그리고 **읽기 전용**으로만 검토한다.
- 주문 라우팅, 브로커 SDK, 실계좌 플래그는 추가하지 않는다.
- LLM 출력은 `RiskManager` 앞단의 연구 계층에만 둔다.

## 성공 기준 (페이퍼 단계)

- 동일 이벤트 스트림을 재실행하면 체결·잔고가 재현된다.
- 전략은 `available_time` 이후의 정보만 본다.
- 모든 페이퍼 체결에 리스크 결정 ID, 참고가, 실제 시뮬 체결가, 모델 버전이 남는다.
- 실데이터는 provenance가 `vendor_read_only`로 남고, 시뮬 데이터와 섞여 “실제처럼” 보이지 않는다.
